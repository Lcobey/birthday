# Birthday website: quick guide

## 1. Personalise
Edit the block at the top of `script.js` (name, message, captions, letter, final message).
Replace `images/photo1.jpg` to `photo5.jpg` with your real photos (same names, square-ish, about 1000px, under 500 KB each).
Replace `music/song.mp3` with your song (the included file is a silent placeholder).
The final page uses your flower animation from `flowers.css`. The hearts there are rose; to go back to the original colors, search `rgb(244, 160, 184)` and `rgb(236, 110, 150)`.

## 2. Publish on GitHub Pages
1. New repository on github.com, set to **Public**.
2. Upload `index.html`, `style.css`, `flowers.css`, `script.js` and the `images` and `music` folders, then **Commit changes**.
3. **Settings > Pages**, deploy from branch **main**, folder **/ (root)**, **Save**.
4. Your URL appears there after 1 to 2 minutes: `https://YOUR-USERNAME.github.io/REPO-NAME/`

## 3. Test on your phone
Tap the gift, check the sound, open the envelope, open each photo, and watch the finale. If you see old content, hard-refresh or use a private tab.

## QR code for the card
Generate it from the final live URL (high error correction, SVG or 2000px+ PNG, dark on light, keep the white border, at least 2.5 cm printed). Test-scan on two phones before printing.
